# 모바일 앱 개발 표준 점검표 (2026-11-16, 2026-11-17 갱신)

대상 표준: 위키 `infra/개발표준_도구/모바일앱_개발표준.md` (2026-11-10 개정).
대상 코드: `apps/mobile` (React Native 0.87.1), `apps/web`, 공용 `packages/ui-common`.

상태 표기:
- **준수**: 원래부터 기준에 맞음
- **보완**: 이번에 고침
- **미흡**: 남은 갭
- **해당 없음**: 이 앱에는 적용되지 않음

| 표준 항목 | 상태 | 내용 / 근거 |
|---|---|---|
| §0 진실의 원천 하나 | 보완 | 설정 형식(`prefs.ts`), 디자인 토큰(`tokens.ts`·`theme.ts`), 문구(`i18n.ts`)를 ui-common 한 곳에 둠. 웹 CSS 변수는 런타임에 토큰에서 생성(`theme-vars.ts`). 앱 버전은 `apps/mobile/package.json` 하나(Android Gradle이 읽고, iOS는 테스트로 일치 강제) |
| §1·§2 스택 | **미흡 (승인 필요)** | RN 사용. 예외 제안서: `docs/adr/0001-mobile-stack-exception.md` |
| §3.3 minSdk 근거 | 준수 | minSdk 24(RN 0.87 템플릿 기본). 실측 대상: SM-N986N(Android 13), LG-F800S(Android 9) |
| §5.2 실측·실기기 검증 | 준수 | 갤럭시 노트20 울트라 실기기: 설정 저장, 화면, 콜드 스타트 |
| §5.3 구버전 캐시 → 신버전 실행 | 보완 | `parsePrefs`가 스키마 없는 구버전·손상·미래 버전 캐시를 폐기. 테스트 `packages/ui-common/tests/prefs.test.ts`, 웹 실측(구버전 값 → 폐기 안내 표시) |
| §5.4 로컬 저장 스키마 버전 | 보완 | `schemaVersion: 1`. 읽기 실패 시 삭제 후 기본값으로 시작하고 크래시하지 않음. 설정 화면에 안내 |
| §5.5 색·타이포 문서화, 권한 목적 고지 | 보완 | 토큰 파일이 문서 역할. 설정 > "권한·개인정보"에 BLE 용도, 위치 권한(Android ≤11), 데이터 외부 미전송, 디버그 보고서 마스킹을 명시 |
| §5.6 웹뷰 렌더링 | 해당 없음 | 웹뷰 미사용. 웹 PWA에는 입력 16px(§5.6.1), `100dvh` 폴백, `min-width:0`, safe-area `max()` 폴백을 적용 |
| §5.7.1 폰트 | 준수 | 시스템 폰트 1종, 숫자는 tabular-nums |
| §5.7.2 크기 스케일 | 보완 | 11·12·14·16·18·22·28만 사용. 모바일은 모든 글자를 `Txt role` 경유로, 웹은 `var(--fs-*)`. 표 밖 값은 `tests/design-tokens.test.ts`가 차단. 고정 컨트롤은 `maxFontSizeMultiplier=1.3` |
| §5.7.4 깨짐 대응 | 보완 | `lineHeight` 1.4~1.6배 정의, 웹 `word-break: keep-all`·`line-break: strict` |
| §5.7.6 간격 4의 배수, 좌우 16 | 보완 | 0·4·8·12·16·24·32만 사용(테스트 강제). 화면 좌우 여백 16 |
| §5.7.6 색 역할 참조, 대비 | 보완 | 화면 코드에 헥스 금지(테스트). 역할 추가: onPrimary·error·warningContainer·onBand 등. WCAG AA 4.5:1을 테스트로 검증. 주의 배지는 흰 글자에서 어두운 글자로 변경(대비 3.0 → 7+) |
| §5.7.7 컴포넌트 규격 | 보완 | 앱바 56·Heading 18, 탭바 56+안전영역·Caption 12, 주요 버튼 52/패딩 24, 보조 버튼 44(터치 48), 리스트 64(최소 56), 배지 24·Micro 11, 터치 영역 48 |
| §5.8 접근성 | 보완 | 아이콘 버튼 라벨, 버튼·탭·라디오·스위치 role/state, 셀·지표 읽기 라벨. 노트20 울트라에서 접근성 트리 자동 점검 8개 화면(개요 빈 화면·데이터, 장치, 밸런스 24S, 상세, 제어 잠금·해제, 설정): **라벨 누락 0, 48dp 미만 0**. 점검에서 찾은 RN Switch(36dp)는 줄 전체가 스위치인 `ToggleRow`로 교체. 웹은 axe-core(wcag2a/aa·best-practice) 8개 화면 **위반 0**(카드 제목 heading-order 수정). TalkBack 음성 완주는 사람 확인 항목으로 남김 |
| §5.8 권한 거부 | 보완 | 거부 시 설명 + "앱 설정 열기" + 데모·미리보기 계속 사용 가능. 반복 요청하지 않음(검색 시작 때만 요청) |
| §5.8 국제화 | 보완 | 하드코딩 문자열 제거(셀 범위 경고, 연결 상태명, 시간 형식, "Bluetooth", "(이름 없음)" 등). 한국어/영어 |
| §5.8 오프라인·딥링크·웹뷰 미디어 | 해당 없음 | 서버·계정·딥링크·웹뷰 없음(로컬 BLE 앱) |
| §5.8 강제 업데이트·킬스위치 | 해당 없음 | 서버 없음. 배포 시점에 재검토 |
| §5.8 성능 예산 | 일부 준수 | 노트20 울트라 릴리스 빌드: 콜드 스타트 `am start -W` TotalTime 191/224/198ms(2초 이내), 탭 전환 14~61ms(5탭×3회, 300ms 이내, JS 탭 수신부터 렌더 후 프레임까지. 로거가 켜져 있을 때 `[perf]` 로그). 1초마다 전체를 다시 그리던 틱을 재연결 카운트다운 중에만 돌게 바꿈. **최저 지원 기기 측정은 미실시**(실기기는 노트20으로 하라는 지시. LG-F800S 측정은 승인 필요) |
| §6 인증 | 해당 없음 | 계정·로그인 없음 |
| §7 릴리스 가드·서명 | 보완 | `scripts/release-guard.sh`: 디버그 서명·비밀 문자열·versionName 검사. 릴리스 서명은 `JK_RELEASE_*` 환경변수 또는 `~/.gradle/gradle.properties`에서 읽음(키는 저장소에 두지 않음). 일회용 테스트 키로 빌드하면 가드 통과(exit 0), 키가 없으면 차단(exit 1)함을 실측(테스트 키는 즉시 삭제). **실제 릴리스 키 생성·보관은 소유자 결정** |
| §7 앱 화면 버전 노출 | 보완 | 설정 > 앱 정보 "버전 0.1.0". Android versionName·versionCode는 package.json에서 생성(기존 템플릿 "1.0"이던 불일치 수정) |
| §7 크래시 수집 | 보완(로컬) | 전역 JS 오류 핸들러·ErrorBoundary(복구 화면)·웹 error/unhandledrejection을 **기기 안에만** 기록(스키마 버전, 최근 10건, 스택 1500자 제한). 제어 탭에서 확인·삭제할 수 있고, 디버그 보고서에 포함. 외부 수집 도구(Crashlytics 등)는 "데이터가 기기 밖으로 나가지 않음" 고지와 충돌하므로 미도입(결정 필요) |
| §7 단계 배포·관측 | 해당 없음(현재) | 스토어 배포 전. 배포 결정 시 재검토 |
| §8 iOS 일정 | 미흡 | iOS는 CI 시뮬레이터 빌드만. 실기기 검증 없음 |
